# Salamander Grand Piano samples

The seven MP3 samples in this directory are recordings of a **Yamaha C5**
from **Salamander Grand Piano**, created by **Alexander Holm**.

Licensed under [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/).
The original author and license notice is retained in [README.source.txt](README.source.txt).

These MP3 files were downloaded unchanged from the
[Tone.js audio mirror](https://github.com/Tonejs/audio/tree/master/salamander).
Original project: [Salamander Grand Piano](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html).

The browser decodes the samples locally and changes playback pitch to follow
the original game's PIT frequencies. No new melody or accompaniment is added.
Native sound effects still use the PC speaker when the piano music option is on.
All samples are embedded in both standalone HTML files; playing makes no
external audio requests.
